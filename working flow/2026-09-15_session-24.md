test was fragile, not the prompt.

## Architectural Decisions

1. **The EDA fix was applied by re-running the deterministic renderer on
   the SAME already-validated narrative, never by asking the LLM again.**
   *Why:* explicit instruction, and it is genuinely unnecessary — the bug
   was 100% in `callbacks.py`'s figure-column selection, already fixed and
   already proven against real data in Session 23; re-spending an LLM call
   to prove a deterministic Python fix works would have been wasteful and
   against this session's own "no LLM call needed for this correction"
   framing.
2. **The feature-curation fix is prompt-only; no deterministic-code
   change.** *Why:* explicit instruction ("Do NOT manually edit
   dataset_contract.json. Do NOT deterministically fabricate an Agent
   semantic decision"); `ContractDraft`'s own validators already correctly
   reject the exact inconsistency the corrective run hit (proof the
   deterministic layer needs no change — it caught a real problem
   correctly).
3. **After the corrective run's critical halt, artifacts were reverted to
   the last known-good, already-merged state rather than left in a
   halted/inconsistent state or hand-patched.** *Why:* leaving
   `dataset_contract.json` missing (or, worse, mixing run 3's
   `clean_data.csv` with run 2's `dataset_contract.json`, which would fail
   the SHA256 integrity check) would either break the repo's own gate or
   require exactly the "manually patch the contract" move this session's
   instructions explicitly forbid. Reverting to a verified-consistent state
   and re-applying only the independently-verified deterministic fix was
   the only option that kept every artifact internally consistent AND
   didn't fabricate anything.
4. **No second live run**, per explicit instruction, even though the
   failure was arguably "close" (correct semantic reasoning, wrong column
   reference). *Why:* the instruction is unconditional ("Do NOT perform a
   second corrective live run" on critical failure) — honored exactly,
   not reinterpreted based on how close the failure seemed.
