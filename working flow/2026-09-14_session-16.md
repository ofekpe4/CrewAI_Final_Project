## Architectural Decisions

1. **Acquisition source: IBM's own GitHub org repo, not Kaggle.** Kaggle requires
   an authenticated API key for scripted downloads (violates the Plan's "no API
   key if a stable public source exists"), and the most common Kaggle listing's
   license is "Not specified." `IBM/telco-customer-churn-on-icp4d` is Apache-2.0,
   official (IBM's own account), and needs no auth. *Why:* reproducibility and
   license clarity both matter more than convenience.
2. **URL pinned to a commit SHA, not a branch.** Confirmed via the GitHub commits
   API that the target file has exactly one commit in its entire history. Pinning
   to that commit is the closest available approximation to an immutable URL;
   documented explicitly that this is *not* a cryptographic guarantee and that
   the SHA256 check is the real integrity lock (per the Plan's own fallback
   instruction for when an immutable URL is unavailable).
3. **`TotalCharges` is redundant, not leakage.** *Why:* leakage requires temporal
   information that would not exist before/independent of the outcome. Source
   evidence places `TotalCharges`, `tenure`, and `Churn` all at the same "end of
   quarter" snapshot; the ~99.96% correlation with `tenure × MonthlyCharges`
   is a multicollinearity fact about redundant features, not a timing fact about
   leakage. The Plan explicitly warns against conflating the two.
4. **No currency invented for `MonthlyCharges`/`TotalCharges`.** *Why:* durable
   project rule (§B, §J.1 criterion 11); the "California" framing is a plausible
   inference but not a source-confirmed fact, so it was deliberately excluded from
   the column's unit metadata rather than smuggled in as a convenience.
5. **pandas installed at `3.0.5` (current latest), not pinned to the Plan's
   illustrative `run_metadata.json` example value (`2.3.3`).** *Why:* that JSON
   block in §Q.4 is a format example, not a version decision in the closed-decisions
   table (unlike `crewai==1.15.20`, which *is* in that table). Verified `3.0.5`
   against PyPI and via a dry-run install that it introduces zero new transitive
   dependencies and no conflict with the pinned `crewai` stack.
6. **Tests skip, not fail, when the raw file is absent**, and perform zero network
   I/O themselves. *Why:* explicit Gate 2D instruction — acquisition and testing
   are different concerns; a CI run without network access (or before the
   acquisition step) should not report false test failures.

### 3 real, measured quality issues

1. `TotalCharges` loads as string, not numeric — 11 rows hold a literal `" "`
   (all `tenure == 0`).
2. 7 service columns (`MultipleLines` + 6 others) conflate "No" with
   "No {phone,internet} service" — a structural dependency on
   `PhoneService`/`InternetService`, not new information.
3. `SeniorCitizen` (`int64`, `{0,1}`) is encoded inconsistently with peer binary
   flags `Partner`/`Dependents`/`PhoneService`/`PaperlessBilling` (`str`,
   `{"Yes","No"}`).

### Scale-sensitive column

`MonthlyCharges` — continuous, range 18.25–118.75, currency intentionally left
unspecified.
