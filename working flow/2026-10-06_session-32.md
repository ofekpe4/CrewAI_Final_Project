   requires concrete evidence of ambiguity/contradiction/staleness before
   touching production prompt text. None of the six agents' text met that
   bar — confirmed by direct reading against the explicit load-bearing-
   rules checklist, not assumed from the agents having been edited
   recently (Session 31's edit was itself already load-bearing and
   correct). Documenting "reviewed, deliberately unchanged" is the
   correct Phase 11 outcome here, not a shortcut.
2. **Documentation additions, not rewrites.** Every doc change this
   session is a new, clearly-scoped section appended to an existing file
   — never a restructuring of existing, already-accurate content. This
   follows the same principle the Agent-Polish Rule states for prompts:
   change only what has concrete evidence of being wrong or missing.
3. **Historical absolute-path mentions in `PROJECT_PLAN.md` and `working
   flow/*.md` left unredacted.** They are evidentiary records of actual
   terminal output / the Plan's own project-setup history, already
   reviewed for this exact concern in Session 8, and explicitly out of
   scope under PROJECT_PLAN.md's own "zero `/Users/...` in code, configs,
   scripts, or README" line — which is about the operational system, not
   session notes. Rewriting them would reduce their evidentiary value for
   a safety property they were never a violation of.
4. **No merge, no PR self-review sequence, no `v1.0.0` tag this
   session.** Internal Gate 11.9 is explicit: "If files are absent, Phase
   11 cannot final-merge/tag yet." The five screenshot files are absent.
   Every other mandatory Phase 11 criterion passed (see Final Definition
   of Done audit in the final report) — but the release sequence is
   correctly withheld on this one still-open item, not performed
   partially or against instruction.
5. **Clean-clone rehearsal used the real `/opt/homebrew/bin/python3.12`
   absolute path, not a bare `python3.12` lookup.** The shell's `$PATH`
   on this machine lists `/opt/anaconda3/bin` before Homebrew — a bare
   `python3.12` would have been ambiguous about which installation
   answered first depending on shell state. The absolute path removes
   that ambiguity entirely, which is the stronger form of the Gate 11.10
   requirement ("Anaconda required: NO"), not a weaker one.
