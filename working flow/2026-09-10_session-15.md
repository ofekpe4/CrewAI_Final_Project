## Architectural Decisions

- **PATTERN A — chosen on runtime evidence, not elegance.**
  - *Primary reason:* **Task 1.3** proved the single deciding question — a
    `Task.callback` in a `Process.sequential` crew runs **synchronously**, **fully
    completes before the next task's agent starts**, blocks the crew loop, and its
    fsynced artifact is readable byte-for-byte by the next agent. **Task 1.4** proved
    the next agent receives the prior task's **final, post-guardrail** output via
    `context=`. So `Agent → validated plan → guardrail → deterministic callback →
    artifact → next Agent` runs correctly inside one crew of 3 sequential tasks —
    exactly Pattern A (§C.2.2).
  - *Why B is not primary:* Pattern B (split each crew into ≥2 `kickoff()` stages with
    Python between them — §C.2.3) exists only for the case where the callback does not
    finish before the next task. Task 1.3 disproved that for `1.15.20`. B adds an
    unusual crew shape and moves orchestration into the Flow for no behaviour A lacks.
  - *Fallback triggers (documented):* a `crewai` bump that breaks the Task 1.3
    callback-timing guarantee; a genuinely-async callback need; guardrail/retry
    semantics that stop critical plans failing visibly; `context=`/`output_pydantic`
    semantics that stop passing the final validated output. Re-run the spikes, switch
    the affected crew to §C.2.3 if a check fails.
- **Production boundaries recorded** in `docs/architecture.md` §14 (guardrails own the
  Pydantic parse; explicit `context=`; contract travels as an artifact not `context=`;
  module-level named callbacks; `guardrail_max_retries=2`; `Literal` handoff names +
  no path param; routers only emit listened labels; wrap crew/gate calls in the Flow;
  gate PASS/FAIL is deterministic Python; no PEP 563 in guardrail modules; all scoped
  to `1.15.20`).
- **Spike files kept, not deleted.** `PROJECT_PLAN.md` §T Phase 1 accepts "deleted **or**
  explicitly marked as deletable"; all six carry a `DISPOSABLE SPIKE` header and are
  retained as reproducible evidence.
- No deviation from `PROJECT_PLAN.md` made or proposed.
